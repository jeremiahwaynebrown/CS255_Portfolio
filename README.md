# CS255_Portfolio
-Briefly summarize the DriverPass project. Who was the client? What type of system did they want you to design?
The DriverPass project involved designing a system to help a client, DriverPass, provide driving test preparation services. The client wanted a system that could handle scheduling, DMV interactions, and a smooth user experience for customers booking driving practice sessions. 

-What did you do particularly well?
I excelled at identifying and organizing the system’s core functionalities, particularly by creating a clear role structure and integrating user-friendly processes for scheduling and test preparation.

-If you could choose one part of your work on these documents to revise, what would you pick? How would you improve it?
If I were to revise one part of my work, I’d refine the documentation around user interactions, ensuring it’s as accessible and intuitive as possible. Enhancing these sections could improve clarity, particularly for non-technical stakeholders.

-How did you interpret the user’s needs and implement them into your system design? Why is it so important to consider the user’s needs when designing?
I interpretted the user's needs by referencing an interview transcript with the client, where plenty of open ended questiuons were asked to help get clarity on what the user needs were. I implemented them by clearly documenting them and translating them into technical requirements and diagrams so that the reader may be able to understand how these needs are designed to be implemented. It is important to consider the user’s needs when designing because user needs drives funcrtionality, ensuring the system address real problems and provides value.

-How do you approach designing software? What techniques or strategies would you use in the future to analyze and design a system?
When approaching software design, I start by analyzing requirements and identifying core user goals. Moving forward, I’d incorporate more user interviews and adopt additional modeling techniques, like flow diagrams and use-case analysis, to refine system interactions and better visualize complex workflows.
